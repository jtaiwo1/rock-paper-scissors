# Command Line Games

This project contains two games:
- 
- Rock Paper Scissors
- Tic-tac-toe

## Rock Paper Scissors

A simple Rock Scissors gample played in the command line.

The player choises between:  **rock, paper, and scissors**

The computer also makes a choice (selected at random), and the winner is selected using the normal Rock Paper Scissors rules.A

## Tic-tac-toe

A simple two-player Tic-tac-toe game played in command line.

Each player takes turns to place their marker on the board using a 1-9 board object representing each square on a tic-tac-toe grid.

The first player to make 3 of their marks line up wins.

## Running the Games

Open the project in your terminal and run the file for the game you wish to play.
